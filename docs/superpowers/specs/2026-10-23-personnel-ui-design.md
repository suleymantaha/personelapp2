# Approved personnel UI design
User approved same-page collapsible team cards, subtle stable team colors,
rank above untruncated names, hidden-by-default appbar search, add and existing
management actions in overflow, no floating add button. Search closes and clears.
Inline reorder mode has team and within-team drag handles, full unfiltered lists,
and reserved Cancel/Save footer. Cancel discards draft. Save is atomic.
Existing personnel fields, memberships, matrix manual order and rank-first export
rules remain unchanged. Approaches considered: separate modal (rejected), separate
team page (rejected), same-screen inline mode (chosen by user).
